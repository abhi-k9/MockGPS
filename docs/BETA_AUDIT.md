## Surface/lifecycle/privacy review

App ID/source namespace/API2 remain stable. Launcher Activity ignores start extras. Only the capability receiver is an ordinary exported automation surface; tile requires BIND_QUICK_SETTINGS_TILE, the AndroidX profile installer requires DUMP, and service/boot/delay components remain private. Exact five raw extras, allowlisted commands, timestamp freshness and independent persisted sequence validation remain; status does not consume ordering. A captured token is capability possession, not caller identity. Rotation/revocation and opt-in defaults are tested. The selected-car observation is owned by Tasker, not independently sensed by MockGPS.

Provider operations and mutable controller state remain on the main looper; FGS permission/type promotion precedes providers. Focused Activity normal service admission avoids the documented cancellation-before-promotion crash; stale generations cannot start or overwrite later state. PendingIntents remain explicit, immutable, identity-separated by component/request, with updated generation extras; recovery discards pending work and never restores consent to inject. Failure cleanup retains journal uncertainty. Snapshot persistence uses atomic preference commits; storage-failure stops cannot be swallowed as success. Existing fake-provider, IPC, real-provider and process recovery coverage is retained.

No runtime dependency was added; each existing core/activity/drawer/map dependency remains used. No extra wakeup, timer or polling was introduced. Provider publication remains1Hz with event-driven UI/notification updates and no automatic retry; battery optimization is not claimed without measurement. No coroutine/DI rewrite was justified for this serialized small controller. UI/battery, multi-user, arbitrary disk faults and consumer/OEM behavior remain hardware/platform limitations.

The app uses FLAG_SECURE for its window/credential dialog and sensitive clipboard metadata where supported; credentials/ownership/policy remain backup/transfer excluded. Genuine fixes are memory-only, filtered for age/mock and migration erases legacy copies; selected synthetic point/camera persist. Map requests disclose IP/viewed regions to the map provider. Other apps' clipboard, configured Tasker UI/backups/run logs and compromised/rooted devices remain outside this app's boundary. Never share configured Tasker exports or genuine coordinates.
